# 我的个人网站

一个使用纯 HTML 和 CSS 的中文个人网站，包含两个独立页面：

- **Home**（`index.html`）：个人介绍。
- **Notes**（`notes.html`）：现有的 5 份 PDF 阅读资料。

两个页面通过顶部 Home / Notes 导航互相跳转，共用 `styles.css`，支持手机屏幕和键盘导航。

## 预览与部署

直接在浏览器中打开 `index.html` 即可预览，也可以使用本地静态服务器。

网站无需安装依赖或构建，可由 GitHub Pages 直接提供。部署时保持两个 HTML 页面、`styles.css` 和 PDF 文件的相对位置不变。
